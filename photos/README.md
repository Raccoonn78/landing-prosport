# Фотографии сайта

Здесь лежат **исходники** всех фотографий, которые используются на сайте.
Сайт берёт не эти файлы, а их сжатые копии (WebP) из `src/assets/photos/` —
их создаёт скрипт сжатия (аналог TinyJPG / TinyPNG).

## Как заменить или добавить фото

1. Положите файл (`.jpg`, `.png` или `.webp`) в нужную папку ниже.
   Чтобы заменить фото — сохраните новый файл с тем же именем.
2. Запустите сжатие:

   ```bash
   docker compose run --rm photos
   ```

   (без Docker: `npm run photos`)
3. Готово — сайт подхватит фото автоматически, править код не нужно.

Порядок фото в ленте и галерее — по имени файла: `01.jpg`, `02.jpg`, …

## Папки

| Папка | Где на сайте | Что класть |
|---|---|---|
| `hero/` | Первый экран — меняющиеся фото | Яркие кадры с тренировок и турниров, горизонтальные |
| `about/` | «О клубе» — два окна с меняющимися фото | Нечётные (`01`, `03`, …) — в большом окне, чётные — в малом |
| `gallery/life/` | Галерея → вкладка «Жизнь клуба» | Любые фото |
| `gallery/fun/` | Галерея → вкладка «Интересные фото» | Любые фото |
| `club/` | Занятия → «Что ждёт в клубе» | Файлы с именами: `trainings`, `attestation`, `competitions`, `camps`, `demos`, `team` (например `trainings.jpg`) |
| `coaches/` | Тренеры | Портрет на прозрачном фоне, имя файла = id тренера: `egorova`, `ignatieva`, `oleynikov`, `pushkareva` |
| `bob/` | Зайчик Боб (талисман) и «Азбука» | PNG на прозрачном фоне: `white`, `white-orange`, `orange`, `yellow`, `green`, `blue`, `red`, `black`. Исходные PDF — в `bob/pdf/` |
| `brand/` | Эмблема клуба в шапке и логотип в подвале | Белые знаки на прозрачном фоне |

Пока в `club/` нет фото, карточки «Что ждёт в клубе» показываются с иконками.
