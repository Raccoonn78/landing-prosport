# ПРОСПОРТ — сайт клуба тхэквон-до

Новый сайт спортивного клуба «ПРОСПОРТ» на **React + TypeScript + Vite**.
Разработка и сборка — в **Docker**, Node.js на компьютере не обязателен.

## Концепция дизайна

**«Путь пояса».** Сайт проходит путь ученика — от белого пояса к чёрному:

- каждый раздел отмечен «своим» поясом: О клубе — белый, Занятия — жёлтый,
  Азбука — зелёный, Тренеры — синий, Галерея — красный, Залы — чёрный;
- полоса прогресса под шапкой при прокрутке «вырастает» от белого пояса к чёрному;
- запись на тренировку замыкает круг: «Каждый мастер когда-то надел белый пояс».

Палитра спокойная: тёплый светлый фон (как ткань добока), чёрный «пояс мастера»
и цвета поясов как акценты — без агрессивных красно-чёрных контрастов,
чтобы сайт был понятен и детям, и родителям, и взрослым ученикам.

## Быстрый старт (Docker)

Разработка с горячей перезагрузкой — http://localhost:5173:

```bash
docker compose up dev
```

Сборка production-версии в папку `dist/`:

```bash
docker compose run --rm build
```

Production-сервер (nginx) — http://localhost:8088:

```bash
docker compose up -d --build web
```

Порты можно поменять переменными окружения `DEV_PORT` и `WEB_PORT`,
например `WEB_PORT=80 docker compose up -d --build web`.

Альтернатива для сборки без compose (BuildKit выгружает только готовые файлы):

```bash
docker build --target dist --output type=local,dest=dist .
```

## Без Docker

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Структура

```
src/
  data/content.ts      ← ВСЕ тексты, телефоны, тренеры, залы, вопросы — правьте здесь
  components/          ← разделы страницы (у каждого свой .tsx и .css)
  styles/global.css    ← цвета, шрифты, кнопки (дизайн-токены в :root)
  hooks/               ← прокрутка, подсветка меню, анимации появления
public/images/         ← фотографии (team/, gallery/, brand/)
Dockerfile             ← этапы: deps → dev → build → dist → production (nginx)
docker-compose.yml     ← сервисы dev, build, web
nginx.conf             ← кэширование, gzip, заголовки безопасности
```

## Что стоит доделать

- **Фотографии.** Со старого сайта доступны только уменьшенные копии (около 350–580 px
  по ширине). Для чёткой картинки замените файлы в `public/images/gallery/` и
  `public/images/team/` оригиналами с теми же именами. Новые фото галереи добавляются
  в массив `gallery` в `src/data/content.ts`.
- **Форма записи.** Сайт статический, поэтому заявка открывает почтовую программу
  с готовым письмом на `prosport-club@mail.ru`. Чтобы заявки приходили автоматически,
  подключите обработчик формы (например, бота Telegram или сервис форм) в
  `src/components/SignUp.tsx` — функция `onSubmit`.
- **Залы.** На старом сайте указано 13 филиалов, а адресов перечислено 7 — остальные
  можно добавить в массив `halls` и привязать к тренеру в `coaches`.
- **Политика персональных данных.** Для формы на рабочем сайте нужна страница политики
  обработки персональных данных (152-ФЗ) — добавьте ссылку рядом с кнопкой «Отправить».
