# ПРОСПОРТ — сайт клуба тхэквон-до

Сайт спортивного клуба «ПРОСПОРТ» на **React + TypeScript + Vite**.
Разработка и сборка — в **Docker**, Node.js на компьютере не обязателен.
История изменений — в [CHANGES.md](CHANGES.md).

## Концепция дизайна

**«Путь пояса» и девиз «Сила для добра».** Сайт проходит путь ученика — от белого пояса к чёрному:

- каждый раздел «носит» свой пояс: первый экран — белый, О клубе — белый с оранжевой полоской,
  Занятия — оранжевый, Азбука — жёлтый, Тренеры — зелёный, Галерея — синий, Залы — красный,
  Вопросы — чёрный;
- полоска под шапкой — настоящий пояс: перекрашивается по разделам, узел едет по ходу прокрутки;
- талисман клуба, зайчик Боб, живёт в углу экрана и переодевается под пояс раздела.

Палитра спокойная: тёплый светлый фон (как ткань добока), чёрный «пояс мастера»
и цвета поясов как акценты — сайт понятен и детям, и родителям, и взрослым ученикам.

## Быстрый старт (Docker)

Разработка с горячей перезагрузкой — http://localhost:5173:

```bash
docker compose up dev
```

Сжатие фото после замены или добавления (см. ниже):

```bash
docker compose run --rm photos
```

Сборка production-версии в папку `dist/`:

```bash
docker compose run --rm build
```

Production-сервер (nginx) — http://localhost:8088:

```bash
docker compose up -d --build web
```

Порты можно поменять переменными окружения `DEV_PORT` и `WEB_PORT`,
например `WEB_PORT=80 docker compose up -d --build web`.

## Без Docker

```bash
npm install
npm run dev      # http://localhost:5173
npm run photos   # сжатие фото
npm run build    # сборка в dist/
```

## Фотографии

Исходники всех фото — в папке [`photos/`](photos/README.md), разложены по разделам сайта.
Скрипт `scripts/optimize-photos.mjs` (на `sharp`) сжимает их в WebP без видимой потери качества
и уменьшает до нужного размера — результат попадает в `src/assets/photos/`,
откуда сайт подхватывает фото автоматически. Чтобы заменить фото:

1. положите файл в нужную папку `photos/<раздел>/` (для замены — с тем же именем);
2. запустите `docker compose run --rm photos`.

Код при этом править не нужно. Подробная таблица папок — в `photos/README.md`.

## Структура

```
photos/                ← ИСХОДНИКИ фото по разделам (hero, about, gallery, club, coaches, bob, brand)
scripts/               ← сжатие фото
src/
  data/content.ts      ← ВСЕ тексты: девиз, почта, преимущества, пояса, фразы Боба и тренеров, залы, вопросы
  data/photos.ts       ← автоматическое подключение фото из src/assets/photos/
  assets/photos/       ← сжатые фото (создаются скриптом, вручную не правятся)
  components/          ← разделы страницы (у каждого свой .tsx и .css)
  styles/global.css    ← цвета, шрифты, кнопки (дизайн-токены в :root)
  hooks/               ← прокрутка, активный раздел, анимации появления
  utils/consent.ts     ← согласие на cookie (для подключения аналитики)
Dockerfile             ← этапы: deps → dev → build → dist → production (nginx)
docker-compose.yml     ← сервисы dev, photos, build, web
nginx.conf             ← кэширование, gzip, заголовки безопасности
```

## Что стоит доделать

- **Фразы тренеров.** Сейчас подпись есть только у Е. О. Егоровой («Тишину поймали»).
  Фразы остальных добавьте в `src/data/content.ts`, поле `quote` у тренера.
- **Фото для «Что ждёт в клубе».** Положите `trainings`, `attestation`, `competitions`,
  `camps`, `demos`, `team` (`.jpg`/`.png`) в `photos/club/` и запустите сжатие.
- **Политика конфиденциальности.** Для баннера cookie и 152-ФЗ нужна страница с политикой
  обработки персональных данных — добавьте ссылку в `src/components/CookieBanner.tsx`.
- **Аналитика.** Если подключаете Яндекс Метрику, запускайте её только после
  `hasAnalyticsConsent()` из `src/utils/consent.ts`.
- **Залы.** Указано 13 филиалов, адресов перечислено 7 — остальные можно добавить в `halls`
  и привязать к тренеру в `coaches` (`src/data/content.ts`).
